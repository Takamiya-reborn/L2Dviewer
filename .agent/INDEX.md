# AI 协作索引

本目录是全工具共享的项目级文档。各条目按「什么任务读什么」组织，只维护项目级持久事实，不放会话性内容。

| 任务 | 读 |
|---|---|
| 新功能 / 改行为，不确定落在哪个文件 | [architecture.md](architecture.md) |
| 提取、烘焙、皮肤目录、资源格式 | [extract.md](extract.md) |
| 动作播放、挂载、交互、物理、视线等运行时行为 | [runtime.md](runtime.md) |
| 已知根因对照（现象 → 机制） | [traps.md](traps.md) |
| 测试命令、布局与编写要求 | [testing.md](testing.md) |
| 代码风格、资产边界等项目约定 | [conventions.md](conventions.md) |

锚点约定：各文档以「文件 + 函数符号」定位实现（不用行号，行号随提交漂移），grep 函数名即达；改代码时同步更新锚点。

维护纪律：

1. **写回须经用户把关**：完成开发或测试后不立即写回，先向用户汇报——做了什么改动、测试结论或根因是什么、是否正确——由用户确认后再回写本目录；擅自回写会让未经把关的结论堆积、越滚越难纠。
2. 只记与代码绑定、可 grep 验证的事实；过期条目立即删除，不留「可能还有用」的。
3. 改了对应代码就顺手更新锚点；发现文档与代码矛盾，先改文档。
4. 一个文件一个主题；新主题开新文件并在本表加一行，摘要写触发词，不写内容概括。
